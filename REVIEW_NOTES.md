# Phase 1 repairs

## Concrete changes

- Replaced Databricks-only magics, S3 mounts, and private bucket dependencies with local CSV inputs.
- Replaced VADER-generated training labels with a human-labelled benchmark; VADER agreement is no longer described as ground-truth accuracy.
- Moved TF-IDF fitting inside the training pipeline and restored an explicit neutral category for rule-based scoring.
- Added error examples, source-specific results, and a portable inference command.

## Scope and remaining limits

Review sentences differ from Black Friday social posts. This benchmark cannot validate neutral classification, establish a Black Friday sentiment distribution, or prove robustness to sarcasm or language shifts. The eight Black Friday example posts are authored illustrations, not collected observations.

The existing `Dashboard for Quicksight.png` is retained as a historical artifact. It is not generated by the current benchmark and does not show the current evaluation results.

Two compact model candidates (one for text) replace expensive grids and unnecessary neural networks.
The current notebook is an executable walkthrough of the Python implementation. Historical versions remain in Git history.
Source folders and unrelated local datasets were read without modification during discovery.

## Validation

- Full CLI execution generated the committed metrics, reports, plots, and held-out predictions.
- The updated notebook was executed with a fresh kernel.
- Saved-model batch inference was checked against the corresponding held-out scores.
- 11 focused pytest checks passed; they cover label validation, split isolation, preprocessing leakage, and task-specific failure cases.

See [results/REPORT.md](results/REPORT.md) and [results/metrics.json](results/metrics.json) for measured evidence.
